Career Rep High Level Design Specs

Skills: provide primary instructions to complete the objective or generate deliverable
Rule: algorithmic decisions that skills and sub-agents use to act
Sub-agents: perform independent tasks and feed information back to the skill to be used
Templates: input structures that skills or sub-agents use to compile information
Scripts: general python scripts used to perform tasks (ie: read or convert a file)
Outputs: folder to temporarily hold outputs that won't remain in the repo and will be moved or deleted at a later time
Personal: a nested private repo that contains a users personal information

(ie: qc, external research, control file reads and deterministic logic (python scripts?), etc)

Lineage, Traceability, Continuity:
- session logging
- application IDs
- research sources (formerly sources)



Design notes: all file and folder names are lower case and words separated by underscore
Apply data engineering and MDM best practices and principles at all times (deviate only when it adds value for scalability, initutiveness, purpose)
Apply DRY (don't repeat yourself)	
All directories and sub-directories will have readme with at least minimal context for the directory without being redundant with parent readmes.  Sub-directory readmes could expand on parent readmes with more granular detailed information or just provide a high level summary of the content for the user/reader.
