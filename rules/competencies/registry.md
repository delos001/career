# Competency Registry

**Used by:** cv_targeted, role_evaluation, experience_inventory

Granular functional Competency values for the entry-level `Competency:` tag in `Experience_Inventory.md`. Multi-value, pipe-delimited. Lowercase kebab format matches other axis value formats. Distinct from specialty-pack capability vocabulary in `rules/specialties/<specialty>.md` (which is fine-grained and specialty-specific) and from Specialty axis values themselves (which describe field-of-practice). Designed for orthogonality with Specialty: no Competency value duplicates a Specialty value. New tag values must validate against this list; expansion is a deliberate edit to this file.

Bottom-up redesign 2026-05: replaced prior 16-term coarse registry derived from initial inventory tags with a 31-term granular registry derived from phrase-level extraction across all 197 inventory entries (`temp/competency_extraction.md`, `temp/competency_clustering_proposal.md`).
