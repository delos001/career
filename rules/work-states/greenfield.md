# Greenfield - CV Framing Rules

**Used by:** cv-targeted, axis-classifier

## Identity

Work where no prior structure, capability, or operating model existed. The deliverable is establishing rather than improving. Characteristic contexts: standing up a new function, building a first-of-its-kind capability inside an organization, founding a startup, originating a process, system, or framework where none existed before.

The work-state does not fit when the work is improving or extending something already in place, even if substantially redesigned. Substantial redesign of an existing capability reads as scaling, mature, or pivot depending on context.

## Achievement framing

Reads as greenfield signal: "first," "established," "originated," "founded," "designed from scratch," "instituted," "stood up." Outcomes describe a capability or structure that did not exist prior. Before-and-after framing is particularly strong because the "before" is genuine absence rather than a baseline to improve.

Reads as off-spec for greenfield: incremental-improvement framing, optimization outcomes, percentage-point gains on existing baselines, harmonization across existing variants. These read as scaling, mature, or turnaround signal even when the underlying work was novel to the candidate.

## Adjacency

Translation signal for entries tagged with adjacent work-states:

- **scaling**: scaling work translates partially when the scaling included net-new components built from scratch; pure replication or expansion of existing models does not carry as greenfield.
- **divestiture**: divestiture work translates as greenfield-flavored when establishing new independent operations was the primary deliverable; pure dependency-severance without standing up new capability does not.
- **pivot**: pivot work translates only when the new direction required net-new capability construction; pure redirection of existing capability does not.
- **turnaround**: turnaround work translates as greenfield only when the rebuild was so complete that it amounted to standing up from nothing; recovery within recognizable prior structure does not.

### Low or no adjacency

- mature
- post-merger-integration
