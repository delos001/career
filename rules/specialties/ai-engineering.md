# AI Engineering — CV Framing Rules

**Used by:** cv_targeted, role_evaluation

## Capability vocabulary

- Production ML system design and deployment
- Model training, fine-tuning, and evaluation
- LLM application development
- Retrieval-augmented generation (RAG) system design
- Prompt engineering and prompt evaluation
- MLOps pipeline design
- Feature store implementation
- Model serving and inference architecture
- A/B testing and online evaluation for ML systems
- Model monitoring and drift detection
- AI safety, evaluation, and alignment practices
- Cross-functional AI delivery

- LLM, foundation model, embedding, transformer
- Fine-tuning, LoRA, PEFT, instruction tuning
- RAG, hybrid retrieval, reranking
- Prompt engineering, chain-of-thought, few-shot, zero-shot
- MLOps, model registry, feature store, model gateway
- Inference, serving, batch inference, real-time inference
- Vector database (Pinecone, Weaviate, Chroma, pgvector)
- Evaluation: eval harness, BLEU, ROUGE, perplexity, win rate
- PyTorch, TensorFlow, JAX, scikit-learn, XGBoost
- HuggingFace, LangChain, LlamaIndex, vLLM
- Anthropic Claude, OpenAI GPT, Google Gemini, Mistral, Llama
- Drift detection, concept drift, distribution shift
