# Specialty Registry

**Used by:** cv_targeted, role_evaluation, inventory, narratives

Specialty values for axis validation per `experience-inventory-domain-scoping`. Per-value framing rules in same-folder files. Tagging by work nature per `specialty-axis-tagging-by-work-nature` (an entry tags every specialty whose work was meaningfully present, regardless of role title).

- **clinical-operations**: study start-up, site monitoring, trial conduct, vendor/CRO oversight, RBQM operations. File: `clinical-operations.md`.
- **quality-compliance**: GxP application, audit and inspection response, CAPA, ALCOA+, CSV/CSA, regulatory framework adherence. File: `quality-compliance.md`.
- **data-engineering**: data pipelines, ETL/ELT, data warehouse/lakehouse, schema design, data quality and observability. File: `data-engineering.md`.
- **ai-engineering**: production ML/LLM/AI system build, MLOps, model deployment, AI capability development as deployed services. File: `ai-engineering.md`.
- **data-science**: statistical programming, statistical and quantitative methods, exploratory and applied analysis, analytic-application development carrying method, applied modeling in research/POC mode. File: `data-science.md`.
- **operations-strategy**: operating-model design, capability strategy and roadmapping, process architecture and improvement, technology and vendor strategy, transformation program design. File: `operations-strategy.md`.
- **people-leadership**: direct people management, coaching, hiring, performance management, organizational design from the people-management lens. File: `people-leadership.md`.
